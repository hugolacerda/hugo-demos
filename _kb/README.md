# Knowledge Base — Local Copy

This folder contains local copies of the Claude project knowledge base files.

## How This Works

The KB files in this folder are the source of truth for Claude's project memory.
They live here in the repo for version control and easy editing, but they must
also be uploaded to the Claude project to take effect in conversations.

## Workflow for Updating KB Files

1. Edit the relevant .md file in this folder
2. Commit and push (same as any other file in the repo)
3. Go to the Claude project settings
4. Re-upload the updated file to replace the old version
5. Claude will use the updated version in all future conversations
