Pricing Guide

This is the reference table for the "Before" column of the AI invoice. Use these rates to calculate what human agency services would cost.

Role Typical Tasks Rate

UX Designer User flows, wireframes, research $175/hr

Frontend Developer Interactive builds, prototypes, code $200/hr
Backend Developer APIs, databases, integrations $200/hr

"After" Column Standards

When building the invoice, use these standards for the "After" (AI-assisted) column:

Line Item Standard
AI costs $1
User time Minutes actually directing/reviewing (not elapsed time)
Revision rounds Unlimited
Delivery Instant
Key principle: The "After" column should dramatically show the time and cost savings by substituting AI for traditional agency services, while maintaining quality.

Five-File Agent Standard

When packaging a workflow as an agent (Step 8), use this standard structure across five files:

File Purpose
01-start-here.html Entry point: manifest, agent training, human training
02-golden-example.html Completed deliverable showing what "done" looks like
03-process.html Machine-readable execution steps with decision rules
04-context.html Input manifest, domain knowledge, reference tables
05-quality.html QC gates with weighted scoring
Standard pattern: This five-file structure ensures any agent can be understood, replicated, and improved by anyone reading the documentation.
