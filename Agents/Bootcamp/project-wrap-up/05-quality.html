Quality Gates

Five gates for evaluating a completed project wrap-up. Run these checks before delivering. Every blocker must pass. No more than two majors remaining. The golden example is the reference standard.

Pass Criteria

  • All blockers pass
  • No more than 2 majors remaining
  • Minors are tracked but don't block delivery
  • Weighted score ≥ 80% to ship

Quality Gates

Gate 1
Invoice Accuracy (25%)

Blockers: Invoice section exists in wrap-up.html; Before column uses realistic pricing from guide; After column shows actual user time + $1 AI cost; Savings badge math is correct.

Majors: Line items match actual work; Hour estimates are defensible; Design matches golden example layout.

Minors: Timeline comparison included; Project context block is complete.

Gate 2
Completeness (25%)

Blockers: wrap-up.html exists in project folder; BLUF section present; System improvements section present; Artifact inventory lists every file with correct paths.

Majors: Suggested improvements section present; Workflow packaging assessment included; Stats grid includes files created, active time, savings, and one project-specific metric.

Minors: Chronology/timeline section included; Next-run checklist included (if repeatable).

Gate 3
Accuracy (20%)

Blockers: File paths in inventory are correct and files exist; Savings calculation is mathematically correct; No improvements claimed that weren't delivered.

Majors: Improvement descriptions match what was actually built; Suggested improvements are specific and actionable.

Minors: Dates and version numbers are correct; Client/project naming is consistent.

Gate 4
Format (15%)

Blockers: Wrap-up uses the production design system (Inter, canonical tokens); HTML is valid and renders correctly.

Majors: Follows golden example structure (BLUF → Stats → Improvements → Suggestions → Packaging → Artifacts); Improvement cards use correct tag colors.

Minors: Responsive layout works on mobile; Footer includes project name, date, and "Produced with Humans+Agents".

Gate 5
Value (15%)

Blockers: BLUF actually summarizes the outcome, not just lists what was done.

Majors: Improvements catalog captures genuine system-level changes; Suggested improvements identify real opportunities.

Minors: Report tells a coherent story from problem to outcome; Invoice savings number is meaningful and contextual.

Scoring

Each gate is scored 0–100. Weighted total must be ≥ 80.

Formula:
(Invoice × 0.25) + (Completeness × 0.25) + (Accuracy × 0.20) + (Format × 0.15) + (Value × 0.15)
Minimum passing score: 80
