Project Wrap-Up Agent

Turn project work into deliverable intelligence. This agent produces a comprehensive wrap-up package: cost analysis, system improvements, workflow documentation, and a final report saved directly to your project folder.

What It Produces

A comprehensive wrap-up report saved to your project folder containing:

  • Embedded Invoice Section — Before/after cost comparison showing traditional costs vs. your actual investment
  • System Improvements Catalog — Documented changes to your workflows, tools, and processes
  • Suggested Additional Improvements — Forward-looking enhancements for the next cycle
  • Workflow Packaging — If applicable, repeatable workflows packaged as agents or templates
  • Artifact Inventory — Complete documentation of every file created or modified

What It Needs

Required

  • Project name
  • Project folder path

Recommended

  • Client name
  • Scope of work / deliverables list
  • Your active time on project

Optional

  • Quality criteria
  • Specific cost comparisons

How to Run

Tell Claude: "Run project wrap-up" or "Let's wrap up the project."

Claude reads this file first, then follows this sequence:

  1. 02-golden-example.html — Study the target output
  2. 03-process.html — Execute the seven-step process
  3. 04-context.html — Reference pricing and routing
  4. 05-quality.html — Run QC gates

Agent Training

Step 1
Study the Golden Example

Read 02-golden-example.html first. This is a completed wrap-up report (the FairPlay half-day session). Internalize the structure: BLUF, stats grid, improvement cards with tags, suggested improvements, workflow packaging assessment, artifact inventory.

Step 2
Gather Inputs

Confirm project name, folder path, and client. Scan the project folder for deliverables, documents, and work artifacts.

Step 3
Build the Invoice Section

Count artifacts produced, build traditional cost estimate based on scope, calculate your actual cost, produce before/after HTML invoice that will be embedded in the wrap-up report.

Step 4
Catalog Improvements

Document system changes made during the project and suggest future improvements based on patterns observed.

Step 5
Package Workflows

If repeatable workflows emerge, package as an agent or template. If not repeatable, note it and move forward.

Step 6
Write Wrap-Up Report

Assemble all outputs into a single wrap-up.html saved in the project folder with the v4 design system.

Step 7
Self-QC

Run quality gates from 05-quality.html. Three-run graduation pattern (same as agent-builder).

Human Training

Job 1
Provide Project Context

Point the agent at your project folder. Tell it the project name and roughly how long you spent on it. Optionally provide client name and scope of work.

Job 2
Review and Iterate

Check the invoice numbers, review suggested improvements, and approve or adjust before finalizing the wrap-up report.
