Process.

Machine-readable steps for ingesting Basecamp homework files, validating five-file completion, scoring complete agents, ranking winners, and producing internal/external HTML reports.

Execution Overview

Follow the steps in order. Do not score quality until completion status has been determined.

Detailed Steps

Step 01
Receive the submission batch

Read all HTML files supplied by the instructor. Preserve filenames, visible titles, nav labels, student names, and timestamps if provided.

Step 02
Group by student and agent

Group files into agent packages. Prefer explicit folder names, filenames, page titles, or repeated nav labels. If ambiguous, create a best-effort grouping and flag the ambiguity in the internal report.

Step 03
Run completion check

Confirm each agent has all five required files: 01-start-here, 02-golden-example, 03-process, 04-context, and 05-quality. Accept a 02-golden-example folder or file. If missing any required file, mark INCOMPLETE.

Step 04
Apply award eligibility rules

Incomplete agents receive feedback but are not scored for Best Agent Built and do not count for Most Agents Built. Complete agents become eligible for both quantity counting and quality scoring.

Step 05
Score complete agents

Use the five gates in 05-quality.html: completeness, accuracy/coherence, process usefulness, context/golden example strength, and deployability/value. Record weighted score out of 100 plus evidence notes.

Step 06
Create individual feedback

For each student, write concise feedback: status, score if complete, strongest element, most important improvement, and next action.

Step 07
Build leaderboards

Create two leaderboards: Most Agents Built and Best Agent Built. Use only eligible complete agents for Most Agents Built. Use the highest-scoring complete agent for Best Agent Built.

Step 08
Apply tie-breakers

Most Agents Built tie-breakers: more complete five-file agents, higher average quality score, earlier timestamp, instructor discretion. Best Agent Built tie-breakers: highest score, strongest process/context/quality alignment, most practically deployable, instructor discretion.

Step 09
Produce internal HTML

Include full scorecards, ranks, award recommendations, red flags, tie-breakers, and copy/paste announcement. Do not include prize language.

Step 10
Produce external HTML

Include student-facing recognition and feedback. Do not expose private rankings, instructor-discretion notes, or sensitive critiques. Do not include prize language.

Decision Rules and Edge Cases

SituationDecision
Student submits one beautiful file but not a five-file package.Mark incomplete. Praise the artifact, but it is not award-eligible.
Student submits five files but they contradict each other.Complete but score down under accuracy/coherence and deployability.
Student submits multiple agents, one complete and one incomplete.Count only the complete agent. Give feedback on both.
Two students tie on quantity.Apply Most Agents Built tie-breakers in order and document the result.
Two agents tie on quality score.Apply Best Agent Built tie-breakers in order and document the result.

Ambiguity Recovery Workflow

Use this workflow when Basecamp submissions are messy, duplicated, renamed, or incomplete.

AmbiguityRecovery actionReport language
Same student submits duplicate files.Use the most recent complete version if timestamp exists; otherwise flag for instructor.“Duplicate files detected; recommendation based on the most complete identifiable package.”
Agent name differs across files.Group by repeated purpose, nav labels, and internal references.“Agent title normalized for review; source names preserved in evidence log.”
Student submits one file containing all five sections.Mark incomplete for five-file structure, but acknowledge strong consolidated draft if substance exists.“Not yet packaged as taught; strong material may be split into the five required files.”
Timestamp is missing.Do not use timestamp tie-breaker.“Timestamp unavailable; instructor discretion remains final tie-breaker.”
