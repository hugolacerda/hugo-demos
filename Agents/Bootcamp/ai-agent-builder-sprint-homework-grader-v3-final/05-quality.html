Quality Gates.

Weighted rubric and acceptance criteria for deciding completion, scoring complete agents, identifying award winners, and separating internal from external reporting.

Pass Criteria

Use this file to determine completion, quality score, and award eligibility.

Complete
All five files present

Eligible for scoring and awards.

Incomplete
One or more required files missing

Not scored for Best Agent Built. Does not count toward Most Agents Built. Receives feedback only.

Shippable
Score 85+ and no blockers

Strong award contender if aligned, useful, and deployable.

Weighted Rubric

Total score = 100 points. Score only complete agents.

GateWeightWhat it measures
Gate 1 — Completeness25%All required files and sections exist; no placeholders; package is structurally sound.
Gate 2 — Accuracy & Coherence25%Files agree with each other; process matches purpose; context supports process; quality gates evaluate the right thing.
Gate 3 — Process Usefulness20%A future AI session could follow the process without prior context; steps are numbered, decision-ready, and specific.
Gate 4 — Context & Golden Example Strength15%Inputs are categorized clearly; reference knowledge is useful; golden example shows what done looks like.
Gate 5 — Deployability & Value15%Agent solves recurring work, has a clear trigger, and can be realistically run by the intended user.

Gate Details

Gate 1 Blocker
Five-file structure

Missing any required file means INCOMPLETE. Stop award scoring.

Gate 1 Major
Required sections

START-HERE includes manifest/training, process has steps, context has inputs, quality has gates.

Gate 2 Blocker
Internal contradictions

Agent purpose, process, context, and quality cannot contradict each other in a way that breaks use.

Gate 3 Major
Executable process

Another AI session can read the process and know what to do, what to read, and what to produce.

Gate 4 Major
Golden example quality

Example is a real deliverable, not a placeholder or generic description.

Gate 5 Major
Practical value

The agent automates recurring work and has a plausible user, trigger, and output.

Tone and Reporting Gates

Internal
Direct and decisive

Rank clearly. Name blockers. Recommend winners. Flag ambiguity and instructor-discretion calls.

External
Warm and standards-based

Encourage students while staying specific. No shame. No vague praise. Always include a next action.

Universal
No prize language

Do not mention the steak dinner gift card or monetary value in any generated report.
