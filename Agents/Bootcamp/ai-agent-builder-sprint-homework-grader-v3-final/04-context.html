Input manifest, five-file student standard, award definitions, tie-breaker rules, and output specifications for grading AI Agent Builder Sprint homework.

Five-File Student Standard

A student agent is complete only when it includes all five files below. These are the standards taught in the sprint and used for grading.

Award Definitions

Award 01
Most Agents Built

Quantity recognition. Count only complete five-file agents submitted from Day 01 through Day 5. Incomplete agents are listed separately and do not count.

Award 02
Best Agent Built

Quality recognition. Select the highest-scoring complete agent using the rubric in 05-quality.html and the tie-breaker rules.

Prize language rule: Do not mention the gift card or prize amount in grader outputs. The grader identifies recognition winners only.

Basecamp Intake Schema

When files arrive without a clean folder structure, use this schema to normalize the batch before grading. Do not assume that a filename alone proves completion.

FieldFormatUse
student_nameTextPrimary grouping key for feedback and leaderboards.
agent_nameTextSecondary grouping key. Use page title, folder label, or repeated nav label if missing.
file_role01 / 02 / 03 / 04 / 05Determines completion status.
original_filenameTextEvidence trail for the internal report.
submitted_atDate/time if availableUsed only after quantity and quality tie-breakers.
ambiguity_noteTextRequired when grouping is inferred rather than explicit.

Grouping rule: If two files could belong to more than one student or agent, include them in the internal ambiguity log and do not use them to break a tie unless the instructor confirms the grouping.

External Student Feedback Template

Use this structure for each student-facing feedback block. It keeps feedback useful without exposing private rankings.

[Student Name]

Status: Complete / Incomplete / Strong submission / Recognition winner

What worked: Name the strongest observable choice in the student’s agent package.

What to improve next: Name one specific, high-leverage fix.

Next action: Give the student a clear action they can complete before the next sprint check-in.

External-report guardrail: Never say “you lost,” “you ranked below,” or “your work was weak.” Use standards language: “not yet complete,” “needs stronger quality gates,” or “next improvement.”
