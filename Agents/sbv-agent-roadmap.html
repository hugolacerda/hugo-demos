Phase 1

Foundation Agents — The Analytical Core

These two agents form the base of the pipeline. Everything downstream depends on their output.
Agent 01 · Recast Worksheet
Recast Worksheet Agent
Takes raw client financials and produces a clean, normalized recast worksheet — the adjusted earnings picture that drives every valuation. Currently done manually by Amanda in Excel, then reviewed by Nancy. The agent handles the mechanical work in minutes.
Built Run 1 — awaiting live test
Inputs
  • Client P&L (3 years preferred)
  • Tax returns (2–3 years)
  • Balance sheet
Output
  • Completed recast worksheet (Excel)
  • Add-backs itemized with source references
  • Adjusted EBITDA / SDE clearly labeled
Waiting on Gary
  • Excel recast template — defines the exact output format
  • Past client financial statement — needed for known-answer live test
Agent 02 · Observations
Observations Agent
Reads the recast worksheet and writes narrative commentary in Nancy's voice — fractional CFO tone. Identifies the 3–4 most material observations and explains what they mean for business value. Solves the gap in Nancy's current ChatGPT attempts: no context, no voice, no client data.
Built Run 1 — QA Test 1 passed
Inputs
  • Recast worksheet (output from Agent 1)
  • Industry context and business description
Output
  • 3–5 structured observations in memo format
  • Finding + value implication + plain language explanation
  • Ready to drop into valuation report draft
✓ No blockers — ready once Agent 1 produces output

Vision

The Progression — Near-Term to End State

Now
Nancy edits drafts
Agents handle mechanical work. Nancy reviews complete drafts, edits, and approves. Still significant time investment but no more writing from scratch.
Phase 2 Complete
Nancy spot-checks
All five agents running. Nancy's review shrinks to QC passes on specific sections rather than full report rewrites. Amanda's manual formatting work is gone.
Maturity
Tiered autonomy
Express and Explore tiers run near-autonomously. Nancy's time concentrates on Certified work where her CVA credential is actually required. Volume scales without headcount.
End State
Productized pipeline
The pipeline becomes a sellable methodology. Matrix-as-a-Service: SBV and GBA offer facilitated agent fleet builds to business owner clients as a value acceleration engagement.
NACVA constraint, acknowledged: Certified valuations require a CVA signature by definition — that cannot be automated away and we are not trying to. The goal is to concentrate Nancy's time on the judgment and sign-off that only she can provide, while agents handle everything that doesn't require her credential. Express and Explore tiers carry no certification requirement and are the primary candidates for near-autonomous operation.
Guardrail

What the Agents Do Not Replace

Nancy
Professional judgment + NACVA sign-off
The professional interpretation, the client relationship, the certified report signature. This is what only Nancy can do and where her time should be concentrated.
Gary
Strategic advisory layer
The discovery call, the engagement decision, the seller relationship, the deal structure. These require judgment, experience, and trust that no agent can replicate.
Both
Client delivery + relationship
The final review meeting, presenting findings, answering hard questions. AI is a draft, not the deliverable. Every report that leaves the office has a human name on it.
