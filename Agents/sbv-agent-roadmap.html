Methodology

SBV's In-House Valuation Approach

This is what the agents are replacing — the manual steps Nancy and Amanda run today.

SBV does not rely on Value Builder's numbers for client-facing valuations. Gary was explicit: "We'll use our methodology for valuing." Value Builder is a nurture, assessment, and advisory tool. The valuation itself follows a three-part in-house process that the agent pipeline is designed to replicate and eventually replace.

The Three-Part Valuation Process
Step 1
Recasting
Raw financial statements are normalized. Owner add-backs (personal expenses, one-time items, above-market compensation) are identified and removed. This reveals the true economic benefit available to a new owner. Output is Seller's Discretionary Earnings (SDE) and EBITDA.
Net Income + all add-backs = SDE
SDE − reasonable owner salary = EBITDA
Step 2
Weighted Earnings
SDE from each year is weighted to produce a single representative earnings figure. Recent years are weighted heavier because they reflect the current state of the business. Standard weighting: 50% most recent year / 30% prior year / 20% two years back. Alternative weightings are run for businesses with unusual trajectories.
Weighted SDE = (Year N × 50%) + (Year N-1 × 30%) + (Year N-2 × 20%)
Step 3
Market Method + Range of Value
An industry multiple is applied to the weighted SDE. The multiple is derived from comparable sold business transaction data (databases + Vertical IQ + Value Builder Scenario Planner). Output is a low/mid/high range of value — not a single number. This is the figure that goes on the cover of the report.
Value Range = Weighted SDE × Industry Multiple (low / mid / high)
Income Approach (TBD): A capitalization of earnings or discounted cash flow component applies to certified engagements. This has not yet been formally scoped for agent development. Nancy defines this step — it is listed as "TBD" in her own process documentation.
Phase 1

Foundation Agents — The Analytical Core

These two agents form the base of the pipeline. Everything downstream depends on their output.
Agent 01 · Recast Worksheet
Recast Worksheet Agent
Takes raw client financials and produces a clean, normalized recast worksheet. Identifies discretionary expenses, owner add-backs, and one-time items. The adjusted earnings picture (SDE and EBITDA) that drives every valuation. Currently done manually by Amanda in Excel — the agent handles it in minutes.
Built Run 1 complete — Gary validated June 11 against utility contractor P&L. "Nearly identical to the Valutrax report."
Inputs
  • Client P&L (3 years preferred — PDF or Excel)
  • Tax returns (2–3 years)
  • Add-backs file (V2 template in input-templates/)
Output — Three Sheets
  • Sheet 1: Per-year recast (Col A source / Col B add-backs / Col C adjusted / Col D notes)
  • Sheet 2: Multi-year normalized summary — all years side by side, % of revenue
  • Sheet 3: SDE/EBITDA summary — high-level only. Agent stops here.

Agent 02 · Observations
Observations Agent
Reads the recast worksheet and writes narrative commentary in Nancy's voice — fractional CFO tone. Produces six structured observations in Gary's defined framework. Solves the gap in Nancy's current ChatGPT attempts: no context, no voice, no client data.
Built QA Test 1 passed — first real run queued against utility contractor recast output. Output pending Gary review.
Inputs
  • Recast worksheet (output from Agent 1)
  • Industry context and business description
Output — Six Observations (Gary's Framework)
  • 1. Revenue growth rate (most recent year + 3-year)
  • 2. Gross profit margin changes
  • 3. Three largest expense categories
  • 4. Expense lines with >10% relative change as % of revenue
  • 5. Operating expense trends year over year
  • 6. Net income — always bridges to SDE as the more meaningful metric

Agent 06 · Forecasting — Exit Planning Tier
Forecasting Agent
Produces a forward-looking pro forma P&L for clients pursuing exit planning (Accelerate tier and beyond). Takes the multi-year recast summary and projects revenue, expenses, and labor forward under defined assumptions. Gary has a detailed philosophy for every line item — this is not a generic forecast tool.
Backlog — Q3
Inputs
  • Multi-year recast summary (Agent 1 Sheet 2)
  • Target revenue growth rate (e.g. 8% annually)
  • Industry context for margin benchmarks
  • Headcount thresholds (Gary defines per engagement)
Revenue + Expense Module
  • Top-line revenue at defined growth rate
  • Advertising projected as % of revenue (Gary's philosophy: franchise-level commitment)
  • Rent at 3% annual increase
  • Other lines: fixed vs. variable rules defined per engagement
Labor Module (separate)
  • Admin / office / sales wages treated separately
  • Headcount thresholds by revenue tier (e.g. assistant GM at $5M, supervisor per $2M)
  • Capacity-based hiring triggers, not time-based
  • Output: when to hire and what type, baked into the forecast
This is an exit planning deliverable, not a standard valuation output. Accelerate tier is effectively exit planning Stage 1. Most valuation clients don't want a forecast — they want to know what the business is worth today. Build this after the core valuation pipeline (Agents 1, 2, 5, 7) is running reliably.

NACVA constraint, acknowledged: Certified valuations require a CVA signature by definition — that cannot be automated away and we are not trying to. Nancy's time concentrates on the judgment and sign-off that only her credential can provide.
Guardrail

What the Agents Do Not Replace

Nancy
Professional judgment + NACVA sign-off
The professional interpretation, the client Q&A call, the certified report signature. The income approach on certified engagements. This is what only Nancy can do and where her time should be concentrated.
Gary
Strategic advisory layer + "the hammer"
The discovery call, the engagement decision, the seller relationship, the deal structure. Knowing when to bring the hammer — and when to put velvet on it. No agent replicates that judgment.
Both
Client delivery + the Scenario Planner conversation
Presenting findings, running the Value Builder Scenario Planner live, showing what improvements would do to value. This is where advisory upsells happen. AI is a draft, not the deliverable.
