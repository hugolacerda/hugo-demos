# gba/newbuild: gatewaybusinessadvisors.com on Astro

A static Astro build of the live site, visually 1:1 with it, deployed on Netlify from this folder (branch `gba-astro-newbuild`, base directory `gba/newbuild`). The map that drives the work is in Hugo's Obsidian KB: `Maps/gba-site-rebuild/map.md`; `BRIEF.md` here is the live-site inventory it was charted from.

## Run

```
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/
```

Node 22.12 or newer. Astro is pinned to 7.3.x because 7.4 wants Node 22.22+ and this Mac runs 22.19 (ticket 08, 2026-10-24); lift the pin once Node is upgraded. `npm run vendor` runs before every dev and build and copies the pinned third-party files from `node_modules` into `public/vendor/` (git-ignored): Bootstrap 5.3.8's CSS (the live site runs 5.0.2; `public/css/bootstrap53-compat.css` keeps the 5.0.2 look, ticket 09), Font Awesome 6.5.2 and the look-alike font files. JavaScript is not vendored: the component scripts import their libraries from npm (Embla 8.6.0, Bootstrap's own Collapse, Modal and Offcanvas sources) and Astro bundles them (ticket 09).

## Layout

| Path | What it is |
|---|---|
| `public/` | The live site's own assets at their live paths (ticket 06): `css/custom.css`, `css/flexslider.css` and `fonts/stylesheet.css` served unchanged, the 104 font files, `images/`, `upload/`. The old jQuery plugins and fancybox's CSS are gone (ticket 09). |
| `public/css/port.css` | The only CSS this port adds: generated by `scripts/port_css.py`, it carries the live heading styles over to the retagged headings and holds the CSS the ticket 09 behaviours need (the Owl Carousel layout rules and items per view, the hero crossfade, closed mobile-menu lists). Edit the script, not the file. |
| `public/fonts/lookalike.css` | Cinzel and Metropolis declared under the names `Trajan Pro` and `Gotham`, so `custom.css` needs no change when the look-alikes are chosen. |
| `src/site.config.ts` | The switches: `FONTS` (`live` or `lookalike`, Hugo's pick at ticket 10) and the site URL. |
| `src/content/` | 640 content files, `.html` with YAML front matter, written by `scripts/extract.py` (ticket 07; its `README.md` documents the format). |
| `src/loaders/html-content.ts` | The content loader: reads those files into the `pages` and `articles` collections, and lifts the headbanner and contact chrome out of page bodies. |
| `src/content.config.ts` | The two collections and their front-matter schemas. |
| `src/layouts/Base.astro` | The page shell: the live head in the live order, header, `<main>`, footer, the two modals. |
| `src/components/` | `SiteHeader` (mobile header, desktop header, off-canvas menu), `SiteFooter`, `ContactBlock`, `ClientLogos`, `HeadBanner`, `ReadinessModal`, `NewsletterModal`, `SchemaLocalBusiness`. |
| `src/lib/html.ts` | Balanced-block extraction and heading retagging on the verbatim HTML. |
| `src/pages/index.astro` | Home. The other eight templates come with ticket 11. |
| `src/scripts/` | The site's JavaScript (ticket 09): `hero.ts` (homepage crossfade slider), `carousel.ts` (Embla on Owl's markup, deals and logos), `bootstrap.ts` (Offcanvas, Collapse, Modal, and the modal openers). The mobile menu and header shrink are the script in `SiteHeader.astro`. No jQuery. |
| `scripts/` | `harvest.py` and `extract.py` (Python, `.venv`), `vendor.mjs`, `port_css.py`. |
| `harvest/2026-10-24/` | The raw crawl the content was extracted from, with `MANIFEST.md` and `REVIEW-LISTS.md`. |

## Rules carried from the map

- 1:1 is what a visitor sees at 1440, 1024 and 390 px. Invisible markup may change; hidden content is not ported; the known live defects are fixed, not copied.
- The visible banner or hero text is the H1 and heading order is correct on every page, with the live styling carried over in `port.css`. No visually hidden text anywhere.
- Every asset path is root-relative.
- Content changed in Chuck's CMS after 2026-10-24 is changed here too.
