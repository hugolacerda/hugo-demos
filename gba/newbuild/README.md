# gba/newbuild: gatewaybusinessadvisors.com on Astro

A static Astro build of the live site, visually 1:1 with it, deployed on Netlify from this folder (branch `gba-astro-newbuild`, base directory `gba/newbuild`). The map that drives the work is in Hugo's Obsidian KB: `Maps/gba-site-rebuild/map.md`; `BRIEF.md` here is the live-site inventory it was charted from.

## Run

```
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/
```

Fidelity check (tickets 10 and 11; the page list and widths are in the script). `tests/serve.py` serves bare slugs (`/start-here`) the way Netlify's Pretty URLs do; `python3 -m http.server` cannot:

```
GBA_FONTS=live npm run build
.venv/bin/python tests/serve.py 8400 dist
.venv/bin/python tests/fidelity.py compare --reference tests/reference/<date> --local http://127.0.0.1:8400 --out tests/reports/<date>
```

Structure check of every built page against the harvest (visible text of all 640 sitemap URLs, the listing order, heading order, internal links) and the pagination test:

```
.venv/bin/python -I tests/structure.py
node --experimental-strip-types tests/pagination.test.ts
```

Redirects (ticket 14): `scripts/redirects.mjs` writes `public/_redirects` before every dev and build (the hand-written rules are in the script; one rule per article for its old `/news-and-events/<slug>` address). `tests/redirects.py` requests every page, rule, legacy URL and trailing-slash URL against a running site and compares the first response; locally through `netlify serve --offline -p 8888` (which emulates the rules but answers trailing slashes with 200, unlike the CDN), for real against staging:

```
.venv/bin/python -I tests/redirects.py --base https://<staging-host>
```

Node 22.12 or newer. Astro is pinned to 7.3.x because 7.4 wants Node 22.22+ and this Mac runs 22.19 (ticket 08, 2026-10-24); lift the pin once Node is upgraded. `npm run vendor` runs before every dev and build and copies the pinned third-party files from `node_modules` into `public/vendor/` (git-ignored): Bootstrap 5.3.8's CSS (the live site runs 5.0.2; `public/css/bootstrap53-compat.css` keeps the 5.0.2 look, ticket 09), Font Awesome 6.5.2 and the look-alike font files. JavaScript is not vendored: the component scripts import their libraries from npm (Embla 8.6.0, Bootstrap's own Collapse, Modal and Offcanvas sources) and Astro bundles them (ticket 09).

## Layout

| Path | What it is |
|---|---|
| `public/` | The live site's own assets at their live paths (ticket 06): `css/custom.css`, `css/flexslider.css` and `fonts/stylesheet.css` served unchanged, the 104 font files, `images/`, `upload/`. The old jQuery plugins and fancybox's CSS are gone (ticket 09). |
| `public/css/port.css` | The only CSS this port adds: generated by `scripts/port_css.py`, it carries the live heading styles over to the retagged headings and holds the CSS the ticket 09 behaviours need (the Owl Carousel layout rules and items per view, the hero crossfade, closed mobile-menu lists). Edit the script, not the file. |
| `public/fonts/lookalike.css` | What ships (ticket 10): Cinzel and Metropolis declared under the names `Trajan Pro` and `Gotham`, so `custom.css` needs no change, with `size-adjust` so lines break where they break live. |
| `src/site.config.ts` | The switches: `FONTS` (`lookalike` by default; `GBA_FONTS=live` swaps in the live faces for fidelity test builds only, never deployed) and the site URL. |
| `tests/` | `fidelity.py` (screenshot a reference and the build at 1440, 1024 and 390 px, pixelmatch them, fail any page and width over 0.5 %), `build_replica.py` (local copies of the live pages in the fidelity list, from the harvest, while the live host serves its captcha), `serve.py` (Pretty URLs and the 404 page, as Netlify), `structure.py` (every page against the harvest, no browser), `pagination.test.ts` (the listing's pagination bar against the 54 live ones), `requirements.txt` (pinned; install into `.venv`). Reference shots, captures and diff images are git-ignored. |
| `src/content/` | 640 content files, `.html` with YAML front matter, written by `scripts/extract.py` (ticket 07; its `README.md` documents the format). |
| `src/loaders/html-content.ts` | The content loader: reads those files into the `pages` and `articles` collections, and lifts the headbanner and contact chrome out of page bodies. |
| `src/content.config.ts` | The two collections and their front-matter schemas. |
| `src/layouts/Base.astro` | The page shell: the live head in the live order, header, `<main>`, footer, the two modals. |
| `src/layouts/Page.astro` | The 16 core pages other than Home and the listing (ticket 11): headbanner, the page's sections verbatim, the contact block. Per-page differences (heading retags, the affiliations Load More and logo strip, the contact page's logo strip) are its `SHAPES` table. |
| `src/layouts/Article.astro` | The 622 articles (ticket 11). |
| `src/layouts/NewsListing.astro` | The News and Events listing, 12 cards a page, cards generated from the articles in the live order (ticket 11). |
| `src/components/` | `SiteHeader` (mobile header, desktop header, off-canvas menu), `SiteFooter`, `ContactBlock`, `ClientLogos`, `HeadBanner`, `ReadinessModal`, `NewsletterModal`, `SchemaLocalBusiness`. |
| `src/lib/html.ts` | Balanced-block extraction, heading retagging and escaping on the verbatim HTML. |
| `src/lib/pagination.ts` | The listing's pagination bar, CodeIgniter's markup as live. |
| `src/pages/` | `index.astro` (Home), `[slug].astro` (the other 16 pages and the 622 articles at their live slugs), `news-and-events.astro` and `news-and-events/[offset].astro` (the listing at `/news-and-events`, `/12`, `/24` ...), `404.astro`. 692 pages in all. |
| `src/scripts/` | The site's JavaScript (ticket 09): `hero.ts` (homepage crossfade slider), `carousel.ts` (Embla on Owl's markup, deals and logos), `bootstrap.ts` (Offcanvas, Collapse, Modal, and the modal openers), `loadmore.ts` (the affiliations Load More). The mobile menu and header shrink are the script in `SiteHeader.astro`. No jQuery. |
| `scripts/` | `harvest.py` and `extract.py` (Python, `.venv`), `vendor.mjs`, `port_css.py`, `redirects.mjs` (writes `public/_redirects`). |
| `harvest/2026-10-24/` | The raw crawl the content was extracted from, with `MANIFEST.md` and `REVIEW-LISTS.md`. |

## Rules carried from the map

- 1:1 is what a visitor sees at 1440, 1024 and 390 px. Invisible markup may change; hidden content is not ported; the known live defects are fixed, not copied.
- The visible banner or hero text is the H1 and heading order is correct on every page, with the live styling carried over in `port.css`. No visually hidden text anywhere.
- Every asset path is root-relative.
- Content changed in Chuck's CMS after 2026-10-24 is changed here too.
